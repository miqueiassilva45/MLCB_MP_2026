Exercício 01


tokens_limpos = []


for palavra in tokens:
    if palavra in stopwords:
        continue
    elif palavra == "comprados":
        tokens_limpos.append("comprar")
    elif palavra == "chegaram":
        tokens_limpos.append("chegar")
    else:
        tokens_limpos.append(palavra)


print(tokens_limpos)
Resposta: Stemming só corta a palavra por regra fixa, então pode sobrar algo que nem existe, tipo "corr". Lematização busca a forma real no dicionário, por isso o resultado sempre é uma palavra válida.
Exercício 02


def validar_intencao(confianca):
    if confianca >= 0.70:
        return "Ação Executada"
    else:
        return "Fallback Acionado"


print(validar_intencao(0.55))
Resposta: Com 20% de threshold o sistema aceitaria qualquer palpite como certo, podendo confundir intenções e executar ação errada com o dinheiro do cliente.
Exercício 03


def calcular_peso_tfidf(frequencia_geral):
    if frequencia_geral == "muito_frequente":
        return 0.1
    elif frequencia_geral == "pouco_frequente":
        return 0.9


print(calcular_peso_tfidf("pouco_frequente"))
Resposta: Palavra comum aparece em tudo e não ajuda a diferenciar nada, por isso peso baixo. Palavra rara é mais específica, por isso peso alto.
Exercício 04


precisao = vp / (vp + fp)
print(f"{precisao * 100:.2f}%")
Resposta: Falso Positivo é compra normal marcada como fraude. Falso Negativo é fraude real que passou. O Falso Negativo é quem gera prejuízo direto.

    "quantidade": 2
}


print(solicitacao)

Exercício 06


def sao_sinonimos(distancia):
    if distancia < 0.20:
        return True
    else:
        return False


print(sao_sinonimos(0.05))
Resposta: TF-IDF só conta frequência, então não vê ligação entre palavras diferentes. Word Embeddings aprende pelo contexto, então sinônimos ficam próximos no espaço vetorial.
